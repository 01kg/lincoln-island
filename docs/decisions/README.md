# 架构决策记录

ADR（Architecture Decision Record）保存影响后续工作的决定及其原因。它不仅用于代码架构，也用于难以轻易撤销的产品、内容和资产流水线决定。

## 状态

- **提议**：正在讨论，不构成项目事实。
- **接受**：当前有效。
- **取代**：被新的 ADR 替换；旧记录保留以说明历史。
- **拒绝**：曾认真考虑但未采用。

## 何时新增 ADR

当选择会影响多个后续任务、迁移成本较高，或未来协作者很可能追问“为什么”时新增 ADR。例如：

- 运行平台、3D 引擎、浏览器范围、渲染路线和核心依赖。
- 岛屿尺度与地形表示。
- 章节/世界状态的数据模型。
- 内容版本、引用政策和资产许可策略。
- 是否引入某项外部服务或运行时依赖。

普通修复、可轻易撤销的实现细节和会话流水不需要 ADR。

## 新记录格式
