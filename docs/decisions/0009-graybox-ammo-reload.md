# ADR 0009：加入灰盒弹药与抬头换弹

- **状态：** 接受
- **日期：** 2026-08-23
- **决策者：** 项目所有者与 Codex

## 背景

当前枪支可以开火并对敌人造成伤害，但没有弹药数量。项目所有者希望显示子弹数量，并通过朝天空射击触发换弹。

## 决定

每把枪使用 `12` 发弹匣和 `48` 发备用子弹。普通开火消耗一发；当玩家将枪口抬向天空并按左键时，若弹匣未满且还有备用子弹，则补满弹匣并扣除备用子弹。当前不加入复杂换弹动画、弹药拾取或不同武器类型。

## 原因

- 让开火资源有限且可在 HUD 中直接核对。
- 保留用户指定的“朝天空射击换弹”操作，不与 `R` 复位键冲突。
- 仍属于可快速验证的灰盒战斗规则。

## 后果

### 正面

- 玩家需要管理弹匣和备用子弹。
- 换弹操作简单、容易在普通浏览器中验证。

### 代价与风险

- 抬头开火不再是普通射击，而是特殊换弹输入，需要在提示中说明。
- 弹药数量和补给规则仍是原型参数，不代表正式游戏平衡。

## 备选方案

- **按键换弹：** 更常见，但不符合本次明确的操作要求。
- **无限子弹：** 无法验证弹药管理和换弹反馈。

## 后续验证

- 普通浏览器中确认每次开火消耗一发、弹匣耗尽后不能继续开火、抬头左键可从备用子弹补弹。
