# ADR 0008：加入受限灰盒敌人与伤害

- **状态：** 接受
- **日期：** 2026-08-23
- **决策者：** 项目所有者与 Codex

## 背景

项目所有者希望已拾取的枪支能够对敌人造成伤害，同时玩家也会受到敌人攻击。当前实现已有枪支拾取和可见开火反馈，但没有命中、敌人或生命值。

## 决定

在当前灰盒纵切中加入少量固定位置敌人、敌人生命值、枪支命中扣血、玩家生命值和近距离接触伤害。敌人被击败后隐藏；玩家生命值归零时回到诊断营地。暂不实现复杂 AI、弹药、掉落、音效、多人或完整战斗循环。

## 原因

- 满足本次明确的敌人和伤害需求，同时限制系统规模。
- 固定位置和程序化几何便于先验证瞄准、命中和受伤反馈。
- 让生命值与复位状态可在 HUD 中直接核对。

## 后果

### 正面

- 战斗交互形成可操作的最小闭环：拾取、开火、命中、击败、受伤和复位。
- 不依赖外部模型或运行时服务。

### 代价与风险

- 项目已暂时超出原先纯阅读伴侣的无战斗纵切，需要重新评估儿童体验和章节语境。
- 固定位置敌人不是完整敌人 AI，不能代表正式游戏设计。

## 备选方案

- **继续只做弹道特效：** 范围更小，但无法验证伤害闭环。
- **加入追踪 AI、弹药和掉落：** 当前验证成本过高，暂不采用。

## 后续验证

- 普通浏览器中确认枪支只伤害敌人、敌人生命值归零后隐藏、接触敌人会扣除玩家生命值。
- 若要加入复杂 AI、弹药或更多战斗规则，先重新评估 MVP 并新增 ADR。
