# ADR 0010：传送后激活敌人的简单游走

- 状态：接受
- 日期：2026-08-23

## 背景

灰盒战斗纵切已经有十个具有人形和面部表情的敌人。它们此前固定在诊断营地的平台上，便于核对数量、命中和伤害，但传送到山顶后仍完全站桩，缺少基本的世界动态感。

## 决策

传送门成功把玩家送到山顶后，激活敌人的简单游走行为。每个存活敌人在营地平台上围绕自己的初始位置沿确定性的短路径移动，并朝移动方向转身；复位时停止游走并把敌人恢复到初始位置。敌人被击败后继续使用现有的倒地和延迟消失流程。

本次不加入寻路、追踪玩家、复杂状态机或跨平台移动。敌人仍属于灰盒战斗验证，不代表正式游戏中的 AI 设计。

## 结果

- 玩家进入山顶区域后，营地敌人会持续四处走动，且不会因浏览器随机数导致复现困难。
- 命中检测和接触伤害读取敌人的当前移动位置。
- 按 `R` 或因生命耗尽复位后，敌人重新站立并等待下一次传送触发。
