# ADR 0002：首阶段定位为阅读伴侣

- **状态：** 接受
- **日期：** 2026-08-12
- **决策者：** 项目所有者与 Codex

## 背景

长期愿望可以包含探索、建设和生存玩法，但项目所有者是独立开发者，尚无游戏开发经验。最初问题来自阅读《神秘岛》时无法仅凭文字稳定理解位置和路线。

## 决定

首阶段不制作完整游戏，而制作一个具有简单互动的 3D 阅读伴侣：允许读者漫游、定位、查看章节路线与地标，并返回原著继续阅读。

## 原因

- 直接解决真实、具体且亲身经历的问题。
- 可以避开战斗、经济、复杂 AI、动画和内容平衡等高成本系统。
- 即使未来不扩展为游戏，阅读伴侣本身也具有完整价值。
- 最小纵切能够验证 3D 空间是否确实改善阅读理解。

## 后果

### 正面

- 范围适合个人开发者逐步学习。
- 地形、移动、地图与章节数据成为清晰的技术主线。
- 美术精度可以服从空间可读性，而不是反过来。

### 代价与风险

- 必须克制加入传统游戏循环的诱惑。
- 若漫游本身缺少引导，可能沦为与阅读脱节的虚拟旅游。
- 儿童阅读体验需要真实用户测试，不能只由成人想象。

## 备选方案

- **直接制作生存建造游戏：** 愿景吸引人，但首期系统和内容规模过大。
- **只制作交互式 2D 地图：** 成本更低，却无法验证“站在人物视角理解空间”的核心吸引力。
- **制作线性章节动画：** 容易观看，但削弱自由定位和主动探索。

## 后续验证

完成一个章节纵切并观察儿童或亲子读者是否更容易复述路线、识别地标，并愿意回到书中。若 3D 漫游没有带来明显帮助，再重新评估表现形式。
