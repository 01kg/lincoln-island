# 最小可行纵切

## 目标

用最少内容验证一个问题：

> 当读者在《神秘岛》中迷失方向时，一个可漫游、与章节同步的 3D 空间，是否能帮助其理解并愿意返回阅读？

这不是整部作品的 MVP，而是用于验证核心体验的第一块纵切。

## 建议范围

以 **第一部分第 18 章** 为候选章节；在完成版本与章节内容核对前，其状态为“待确认”。纵切只实现：

- 一座轮廓可辨、比例经过体验压缩的灰盒林肯岛。
- 一个可控制的观察者，以及足够稳定的第一人称或第三人称漫游。
- 一张可开关的 2D 地图，显示玩家位置和朝向。
- 一个章节选择界面；首版可以只有一个可选章节，但数据结构不能把章节写死。
- 3～5 个与所选章节密切相关的地标。
- 一条人物在本章的主要行动路线，可显示、隐藏和跟随。
- 到达地标时出现简短、无剧透的阅读锚点，例如章节位置或一句非替代性的提示。
- 自由漫游与“跟随本章路线”两种使用方式。

## 明确不做

- 完整战斗循环；当前纵切按 ADR 0007、ADR 0008、ADR 0009 和 ADR 0010 验证受限开火、固定位置/简单游走敌人、生命值、伤害和灰盒弹药反馈。
- 采集、制作、经济、科技树或建造玩法。
- 多人、账号、云存档或用户生成内容。
- 完整 NPC 表演、对白树、过场动画或复杂角色动画。
- 对整部小说的章节覆盖。
- 写实级模型、电影级灯光或完整生态模拟。
- 发布版本运行时调用混元生成任意模型。
- 大段重述或展示仍受保护的现代译本文本。

## 验收标准

纵切达到以下条件，才考虑扩大范围：

1. 新读者无需开发者口头解释，能够进入世界、移动并打开地图。
2. 玩家位置和路线在 2D 地图与 3D 世界中相互对应。
3. 读者完成一次路线后，能够指出至少三个地标的相对位置。
4. 所选章节中尚未知晓的内容不会因标签、模型或提示而提前暴露。
5. 在一份章节数据中修改地标状态或路线后，世界无需复制场景即可重建。
6. 从全新检出仓库到运行纵切，有书面步骤且不依赖未登记的本机文件。

## 美术预算原则

- 灰盒阶段允许使用 Terrain、基础几何体、纯色材质和占位图标。
- 只有影响辨认或路线理解的地标，才优先制作独特模型。
- 引入生成式模型前，先定义尺寸、朝向、原点、面数、材质和碰撞规范。
- 每个正式资产都要记录来源、生成输入、模型版本、许可和人工修改。

## MVP 之后才评估

- 多章节切换与建设过程动画。
- 更多人物路线和同章不同视角。
- 朗读、词汇解释和教师模式。
- 天气、季节、昼夜与章节气氛。
- 轻量互动、收集或知识型任务。
- 从阅读伴侣逐步生长为完整游戏的可能性。
