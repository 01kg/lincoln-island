# 产品愿景

## 一句话愿景

让读者能够走进《神秘岛》的空间，在不被剧透的前提下理解“人物此刻在哪里、从哪里来、要到哪里去”，从而更愿意也更容易继续阅读原著。

## 我们解决的问题

《神秘岛》包含大量地名、路线、探索和建设过程。只依靠连续文字，尤其是儿童读者，很容易混淆方向、距离以及地点之间的关系。传统地图能够辅助定位，却把不同时期才出现或命名的地点全部压在同一平面上，也无法呈现从人物视角看到的空间。

Lincoln Island 将地图中被压缩的时间重新展开：读者选择章节，看到整座岛在该章的物理状态与认知状态，并能亲自沿路线漫游。

## 核心受众

- 正在阅读《神秘岛》的儿童和亲子家庭。
- 需要地理辅助、章节回顾或课堂展示的教师与学生。
- 希望以空间方式重温小说的普通读者。

首要设计对象是儿童读者，但不通过幼稚化表达排斥成人。

## 核心体验

1. 读者在书中遇到陌生地点或路线。
2. 打开 Lincoln Island 并选择当前章节。
3. 系统将整座岛切换到该章状态，隐藏尚未知晓的内容。
4. 读者查看当前位置、地标和人物路线，或亲自走一遍。
5. 读者形成空间记忆，回到原著继续阅读。

## 体验支柱

### 可定位

读者随时知道自己在哪里，以及当前地点与本章事件的关系。

### 可漫游

空间不是只能缩放的立体插图；读者可以自由行走、观察视线、感受距离。

### 随章节生长

自然地理大体恒定，人类建设逐步出现，名称与秘密只在书中合适的时刻揭晓。

### 引导阅读而非替代阅读

产品提供空间线索、简短提示和回到书中的锚点，不复述整章，不把探索变成跳过原著的捷径。

### 风格清晰而非写实炫技

优先保证轮廓、地标、路线和交互清楚。低多边形或绘本式视觉完全可接受，只要全岛风格统一并适合长时间观看。

## 成功意味着什么

- 一个原本会在地名和路线中迷失的孩子，能说清人物在岛上的移动。
- 3D 漫游增加继续阅读的兴趣，而不是把注意力永久带离书本。
- 章节状态不会错误剧透后续秘密。
- 小团队可以持续增加章节和地标，而不必复制整座岛或手工维护大量互相冲突的场景。
